# Understanding Computer Memory

**Background**  
This is a continuation of my in-completed [mutlicore-memory article](https://minics.dev/articles/multicore-memory/), but now we are going to look at memory as a whole.

In this work, I will provide comprehensive code examples, with the goal that one should be able to learn about computer memory by using this repository.

**Examples!**  
We will include examples and scripts for you, yes you, to run and see live.
Test these examples out on your architecture and see how the literature matches to reality.
I firmly believe this is critical in understanding these very abstract concepts.
